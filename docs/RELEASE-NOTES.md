# על הספה שלנו

ערב משחקים קטן על הספה: בטלפון, ובטלוויזיה עם Android TV. לכל בית ספה משלו, עם שחקנים, היסטוריה וניקוד; וחברים יכולים להתארח זה אצל זה.

## 📱 התקנה בטלפון (Android)

**[הורדה לטלפון](https://github.com/stevenbarzilay-cloud/Al-hasapa/releases/latest/download/al-hasapa-phone.apk)**

1. פותחים את הקישור בטלפון, והקובץ יורד.
2. פותחים את הקובץ שירד. אם הטלפון שואל, מאשרים לדפדפן להתקין אפליקציות.
3. פותחים את האפליקציה ובוחרים «הקמת ספה משלי».

## 📺 התקנה בטלוויזיה (Android TV / Google TV)

**[הורדה לטלוויזיה](https://github.com/stevenbarzilay-cloud/Al-hasapa/releases/latest/download/al-hasapa-tv.apk)**

1. בטלוויזיה מתקינים מחנות Play את האפליקציה Downloader.
2. מקלידים בה את הכתובת:
   `github.com/stevenbarzilay-cloud/Al-hasapa/releases/latest/download/al-hasapa-tv.apk`
3. מאשרים את ההתקנה, פותחים את האפליקציה, ובוחרים «הצטרפות לספה קיימת».
4. בטלפון: «הספות שלי» ← בוחרים בטלוויזיה ← «לחבר אותה לספת הבית שלי», ומקלידים את הקוד שמופיע בטלוויזיה.

אפשר גם להוריד את קובץ הטלוויזיה בטלפון ולשלוח אותו לטלוויזיה באפליקציה כמו Send files to TV.

---

הקישור הזה מיועד להתקנה בלבד. אין בו שום פרט על ספה, על שחקנים או על היסטוריה, ופתיחתו במכשיר שהאפליקציה כבר מותקנת בו לא משנה בו דבר.
